# ROADMAP

## Long-term Structural Milestones

1. **MVP Development (Phase 1):** Complete mobile-responsive Next.js web application encompassing profile creation, skills/needs definitions, basic location matching, and messaging.
2. **Identity Verification Integration (Phase 2):** Implement mandatory identity verification flows utilizing Stripe Identity or Persona webhooks to gate DMs and task posting.
3. **Safety & Onboarding Gates (Phase 3):** Establish "Public First" programmable milestone gates, restricting access to home-based tasks until users complete required introductory meetings.
4. **Mobile App Native Shell (Phase 4):** Transition or bridge Next.js web app capabilities into a React Native (Expo) app for improved native experiences and notifications.
5. **Community Scaling (Phase 5):** Optimize location-based database querying using PostGIS and expand community management tools.
