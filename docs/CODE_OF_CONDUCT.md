# The Village Code (Code of Conduct)

1. **Act from Pure Intent:** Engage each person with dignity, humility, and absolute respect for their journey and household.

2. **Never Exploit:** Help is rendered freely to build real human connection. Coercion, transactional pressure, or entitlement have zero tolerance on this platform.

3. **Protect the Hearth:** Users who violate safety measures, post deceitful identities, or endanger household peace are permanently removed.
