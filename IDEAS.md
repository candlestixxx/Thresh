# IDEAS

## Feature Expansions & Pivot Thoughts

*   **Vouching System:** A user needs a certain number of community "vouches" to upgrade their trust tier, unlocking broader radius matching or more home-oriented task requests.
*   **Timebanking Integration:** While no money can be exchanged, could introduce a soft "timebank" or "karma" system where helping others earns you points to request help, enforcing reciprocity mechanically.
*   **Family-Safe Chat:** Filter mechanics that detect aggressive or inappropriate language in chat, putting the message in a holding state for review, given the family-centric nature.
*   **Language Porting:** If React Native proves too heavy, consider evaluating Flutter for the mobile app shell to easily support diverse and highly accessible UI libraries out of the box.
*   **Group Tasks:** Allow multiple people to sign up for larger aid tasks (like moving furniture or large yard cleanups), turning a 1-on-1 meetup into an instant small community gathering.
